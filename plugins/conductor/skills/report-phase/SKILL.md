# Report the phase result

Report completed or existing work retrospectively. This capability can run on its
own; it does not start execution or prescribe a planning mode or human checkpoint.
Follow [repository scope](../../references/repository-scope.md) for tracked local
artifacts and [phase artifacts](../../references/phase-artifacts.md) for the saved
report path and review lifecycle. Read [checkpoint delivery](references/checkpoint.md)
before authoring or repairing the report.

Use $onepersonlabs:write's concise-report guidance when it is available. Explain
what changed for the intended outcome, what the evidence establishes and what
remains unfinished. Keep consequential limits beside the claims they qualify.
Recover current facts from the conversation, commits, checks, review and existing
work records; do not reconstruct a command diary or create another task registry.

Copy [the static HTML template](assets/navigation.html) into the tracked report
location, then replace all illustrative content. Preserve its static responsive
graph, numbered bold named cards, owner/status descriptions, native story links,
supported branches and reunions, phone layout and print behavior. Do not fabricate
branches, mark interrupted review as approval or hide unfinished delivery.

Account for preparation, implementation, verification, coordination, rework and
waiting when those distinctions affect the result or next decision. Keep unknown
time and AI usage unknown. Compare only equivalent work and do not sum parallel
durations as elapsed time. Reuse an existing workflow account instead of adding a
ledger. If $onepersonlabs:optimize-workflow is available and useful, use its
findings; otherwise state observed costs, repeated work and the supported
improvement without requiring another skill.

Open the saved HTML directly and inspect at 360 pixels, the 768-pixel transition,
desktop width and print. Check graph/story links, keyboard focus, long labels,
arrow directions, branch endpoints and reunions. Confirm no scripts, horizontal
overflow, clipped content or nested scrolling. Report rendered evidence separately
from unobserved human comprehension.

Return a concise result and a clickable link using the report's absolute path.
Repair the same report in place. If it adds a final documentation delta after
implementation review, commit it and return that delta to the same reviewer for
confirmation of the final exact head. Reuse unaffected evidence. Report authorship
does not authorize issue closure, publication, implementation or another phase.
