# Symphony Lite development

The shipping plugin and CLI live under `plugins/symphony-lite/`. Tests and
repository drivers live outside that package. Edit source, not installed caches.

Preserve the distinction between GitHub work status and local machine recovery
metadata. Never infer delivery from a completed model turn. Retain the original
builder thread and workspace through repair and restart.

Run affected deterministic checks and the installed-package checkpoint before
publication. Do not add skill invocation tests or permanent model evaluations.
The initial live qualification is limited to four small issues, eight total
Codex turns, and two concurrent builders. Record actual usage and stop at the
budget. No production dispatch is authorized by development or installation.

Stage only owned files. Parallel writers use isolated worktrees and branches;
the root integrates and owns issue writes and publication. Preserve unrelated
work and existing repository-specific permission boundaries.
